# 这套系统怎样学习

学习链路是：QMT 行情 -> 固定研究池 Tick -> 5 秒特征样本 -> 等待未来 60 秒结果 -> 自动训练 -> 未见数据验证 -> 研究观察。

电脑使用什么时区都不影响交易时段。后台统一按上海时间采集，并在午休 11:35 和收盘后 15:10 检查训练条件。电脑、QMT 和后台进程仍然需要运行。

现有研究模型包括 Logistic Regression 和 HistGradientBoosting。它们从已有样本学习特征与未来结果的关系；没有使用大语言模型来直接猜涨跌。

数据不能凭空出现。没有新样本时，重复运行训练只会重复使用旧经验。因此现在要求至少新增 100 条有效、已标记样本，并检查数据时效；数据库读取失败也会暂停训练。

手机“机器学习进度”会显示：数据截至日期、有效样本数、新增样本数、今日已标记数、当前学习状态，以及研究模型的验证结果。电脑还会保存 `AStockData/reports/learning_progress.csv`。

状态含义：

- 等待有效样本：尚无可以训练的数据。
- 等待新行情样本：现有训练数据太旧。
- 等待样本增量：还没有足够的新经验。
- 等待训练时段：有新数据，等待下一次午休或收盘检查。
- 正在训练：模型正在拟合样本。
- 训练异常：需检查数据或训练日志。

训练成功不等于模型有效。准确率、净收益优势、信号覆盖率和多个未见交易日的表现都要评估。历史数据上的反复试验不能包装成新的前瞻验证。

方向分和结构可信度仍由现有手机模型提供，不等于机器学习预测概率。研究模型不会自动替换手机模型，更不会自动下单。通过验证后的上线仍需要明确决定。

这次修复保留了方向评分与权重，也保留了已经冻结的研究规则。每天冻结的 Shadow 模型会记录文件哈希；文件内容变化时会拒绝继续评分。
